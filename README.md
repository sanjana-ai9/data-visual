# Day 26 – Sales Data Visualization

## Objective
To analyze sales data and represent it using different charts.

## Tools Used
- Python
- Pandas
- Matplotlib
- Jupyter Notebook

## Tasks Completed
1. Created a sales dataset.
2. Displayed dataset information.
3. Calculated total and average sales.
4. Created a bar chart.
5. Created a line chart.
6. Identified highest and lowest sales.
7. Observed sales trends.

## Key Observations
- June recorded the highest sales (25,000).
- January recorded the lowest sales (12,000).
- Sales decreased in April.
- Sales increased again in May and June.

## Learning Outcome
Learned how to visualize sales data using bar charts and line charts with Matplotlib.
